# Тур на один день

За один день вы научитесь **читать** TrueDSL. Не нужно ничего знать о программировании. Читайте по порядку, у каждого урока есть блок «Читаем вслух» — прочитайте код своими словами, как рассказ.

Время: около часа. Если захочется — пробуйте менять числа и слова в примерах прямо в VCode.

---

## Урок 1. Первый скрипт

```
# Это комментарий — компьютер его пропускает
when start
  print "Привет, мир!"
```

**Читаем вслух:** «Когда игра началась — напечатай „Привет, мир!“».

- `when start` — **событие**: «когда это случится». `start` — «объект появился в игре».
- Строки под `when` сдвинуты на **два пробела** — это то, что делается *в ответ*.
- `print` выводит текст в консоль студии.

> Запомните: **отступ = «это внутри»**. Два пробела, не больше и не меньше.

## Урок 2. Двигаем героя

```
when key right held
  move right by 60 per second

when key left held
  move left by 60 per second
```

**Читаем вслух:** «Пока зажата клавиша вправо — двигайся вправо на 60 в секунду. Пока зажата влево — двигайся влево на 60 в секунду».

- `held` — «зажата». Сработает в каждом кадре, пока вы держите клавишу.
- `per second` — «в секунду». Скорость получается одинаковой на любом компьютере.
- Хотите быстрее? Замените 60 на 120.

Ещё один вид события — `pressed` («в момент нажатия»), он срабатывает один раз:

```
when key space pressed
  play sound "jump.wav"
```

## Урок 3. Запоминаем

**Переменная** — это коробочка с именем, в которую можно положить значение.

```
var speed = 60
var lives = 3

when key right held
  move right by speed per second

when touch "enemy"
  lives -= 1
  print "Осталось жизней: {lives}"
```

**Читаем вслух:** «Есть коробочка speed, в ней 60. Есть коробочка lives, в ней 3. Когда касаюсь врага — убавь lives на 1 и напечатай, сколько жизней осталось».

- `var` — создать коробочку. Делается один раз.
- `lives -= 1` — «уменьши на 1». Так же есть `+=`, `*=`, `/=`.
- `"... {lives} ..."` — в тексте фигурные скобки подставляют значение.
- Числа считаются как обычно: `+ - * /`, а `%` — остаток от деления.

## Урок 4. Решаем

```
when touch "enemy"
  lives -= 1
  if lives is 0
    print "Игра окончена"
  else if lives is 1
    print "Последняя жизнь!"
  else
    print "Ничего, продолжаем"
```

**Читаем вслух:** «Если жизней ноль — пиши „Игра окончена“. Иначе, если одна — „Последняя жизнь!“. Иначе — „Ничего, продолжаем“».

- Равно проверяется словом **`is`**. Знак `=` — только чтобы *положить* значение в коробочку.
- Не равно: `is not`. Больше и меньше: `>`, `<`, `>=`, `<=`.
- Соединять условия: `and` («и»), `or` («или»), `not` («не»).

```
if lives > 0 and key space is held
  print "Прыгаю!"
```

- `key space is held` — «клавиша пробел сейчас зажата».
- Результат любого условия — **да** (`yes`) или **нет** (`no`).

## Урок 5. Повторяем

```
repeat 3 times
  print "Раз!"

for each i in 1 to 5
  print "Номер {i}"

var coins = ["золото", "серебро", "медь"]
for each coin in coins
  print coin

var n = 1
while n < 100
  n *= 2
```

**Читаем вслух:** «Повтори три раза: напечатай „Раз!“. Для каждого числа i от 1 до 5 напечатай номер. Для каждой монеты из списка — напечатай её. Пока n меньше ста — удваивай n».

- `[ ... ]` — **список**: несколько значений под одним именем. Первый элемент — `coins[1]` (счёт **с единицы**, как в жизни).
- Не бойтесь бесконечных циклов: движок остановит слишком долгий цикл и скажет, где ошибка.

## Урок 6. Реагируем на мир

События — главное в TrueDSL. Вот основные:

```
when start                       # объект появился
when update                      # каждый кадр
when click                       # по объекту кликнули
when touch "coin"                # коснулся объекта с меткой coin
when message "game over"         # пришло сообщение
when every 2 seconds             # повторяется каждые 2 секунды
```

**Касания.** Объектам в студии можно дать **метку** (`tag`), например `coin`. Тогда:

```
when touch "coin"
  destroy other
  play sound "coin.wav"
```

**Читаем вслух:** «Когда коснулся монеты — удали эту монету и проиграй звук».

`other` — «тот, кого я коснулся». `self` — «я сам».

**Сообщения** — как записки между объектами:

```
# в скрипте героя
when touch "coin"
  destroy other
  send "coin collected"

# в скрипте счётчика
shared coins = 0

when message "coin collected"
  coins += 1
  text = "Монет: {coins}"
```

Герой не знает про счётчик, счётчик — про героя. Они общаются через сообщение. Это упрощает любую игру.

## Урок 7. Ждём

```
when click
  hide
  wait 2 seconds
  show
```

**Читаем вслух:** «Когда кликнули — спрячься, подожди две секунды, покажись снова».

- `wait` ставит на паузу *только этот* кусок кода, остальная игра идёт как обычно.
- `slide to 200, 40 in 1 second` — плавно переехать в точку за секунду.
- Нельзя использовать `wait` в `when update` и `when key … held` — они работают каждый кадр. Если случайно сделаете — движок объяснит.

## Урок 8. Свои команды

Если один и тот же кусок кода повторяется, дайте ему имя:

```
to heal(amount)
  lives = min(lives + amount, 3)
  print "Жизней: {lives}"

when key h pressed
  heal(1)
```

**Читаем вслух:** «Научу команду heal: она принимает количество, прибавляет столько жизней, но не больше трёх. Когда нажали H — вылечи на один».

- Свои команды начинаются со слова **`to`** («чтобы…»).
- Вызываются с круглыми скобками: `heal(1)`.
- Встроенные **команды-слова** (`move`, `show`, `play`) — без скобок; **функции** (`min(…)`, `random(1, 6)`) — со скобками.
