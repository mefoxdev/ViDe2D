# Сообщения об ошибках

TrueDSL рассчитан на новичков, поэтому ошибки пишутся **человеческим языком**: что случилось, где, и что сделать.

> Версия спецификации 0.1 (черновик). Тексты сообщений могут измениться, коды — нет.

## Как выглядит ошибка

```
Проблема в hero.tdsl, строка 7 (TD004):

    move rigth by 5
         ^^^^^
Я не знаю направления «rigth». Может быть, вы хотели «right»?
```

Каждое сообщение состоит из четырёх частей:

1. **Где** — файл и строка, со стрелкой на нужное место.
2. **Код** — `TDnnn`, по нему удобно искать в документации и спрашивать у ИИ.
3. **Что случилось** — одним предложением, без жаргона.
4. **Что делать** — подсказка или вариант исправления («Может быть, вы хотели…»).

Ошибки из кода показываются в VCode прямо в строке, в консоли студии они выводятся с кодом.

## Три вида ошибок

| Вид | Когда обнаруживается | Что происходит |
|---|---|---|
| **Синтаксис** (`TD0xx`) | при открытии и сохранении скрипта | игру не запустить, пока не исправлено |
| **Проверка** (`TD1xx`, `TD2xx`) | перед запуском | игру не запустить, пока не исправлено |
| **Выполнение** (`TD3xx`, `TD4xx`) | во время игры | останавливается только этот запуск обработчика; игра идёт дальше |

## Коды

### Синтаксис — `TD0xx`

| Код | Сообщение | Типичная причина |
|---|---|---|
| TD001 | Неверный отступ: нужно 2 пробела на уровень | сдвиг на 1, 3 или 4 пробела |
| TD002 | В отступе табуляция: используйте пробелы | вставили Tab |
| TD003 | Не закрыта кавычка | `print "привет` |
| TD004 | Не знаю это слово | опечатка: `move rigth by 5` |
| TD005 | Здесь ожидалось другое | `if lives` без продолжения; `move right` без `by` |
| TD006 | Не закрыта скобка | `min(a, b` |

### Имена — `TD1xx`

| Код | Сообщение | Типичная причина |
|---|---|---|
| TD101 | Нет такой переменной | опечатка или забыли `var` |
| TD102 | Такое имя уже есть | второй `var hp` с тем же именем |
| TD103 | Это слово занято языком | `var x = 5` — `x` свойство объекта |
| TD104 | `wait` нельзя в обработчиках, которые срабатывают каждый кадр | `wait` внутри `when update`; то же во время игры, если такой обработчик (или начальное значение `var`) вызывает команду `to`, в которой есть `wait` или `slide` |
| TD105 | Общая переменная объявлена дважды | `shared coins` в двух скриптах |
| TD106 | У объекта нет такого свойства или переменной | `Hero.speeed`: статически не проверяется; во время игры, если переменной нет в скрипте объекта, выдаётся эта же ошибка |
| TD107 | Нельзя изменить только для чтения | `name = "x"` |

### Типы — `TD2xx`

| Код | Сообщение | Типичная причина |
|---|---|---|
| TD201 | Нельзя сравнить число с текстом | `if score is "10"` |
| TD202 | Условие должно быть «да» или «нет» | `if score` |
| TD203 | Неверное число значений для команды | `random(1)` |
| TD204 | Нельзя сложить число с текстом | `"Счёт: " + score` — используйте `"Счёт: {score}"` |
| TD205 | Ожидалось другое по смыслу | `move heading by "5"` |

### Во время игры — `TD3xx`

| Код | Сообщение | Типичная причина |
|---|---|---|
| TD301 | Деление на ноль | `a / 0` |
| TD302 | Нет элемента с таким номером | `items[0]` (нумерация с 1) или номер больше длины |
| TD303 | Тут пусто или объект уже удалён | `find("Ghost").x`, когда объекта нет; используйте `exists(...)` |
| TD304 | Файл не найден или не подходит | `play sound "no.wav"`; файл больше 32 МБ, не звук или повреждён; путь выходит из проекта; шаблон `spawn` не найден; `image = "no.png"` |
| TD305 | Нет такой сцены | `go to scene "lvl9"`; сцена не открывается (повреждён файл, это не сцена) |

### Лимиты — `TD4xx`

| Код | Сообщение |
|---|---|
| TD401 | Слишком много шагов: возможно, бесконечный цикл |
| TD402 | Слишком много памяти (список или текст слишком большой); слишком много сообщений `send` за кадр; в памяти игры больше 1000 ключей или 1 МБ (`remember`); слишком много ждущих обработчиков (`wait`, `slide`) |
| TD403 | Слишком много объектов (`spawn` создаёт не больше 5 000 живых объектов) |
| TD404 | Слишком глубокие вызовы: команда вызывает сама себя без остановки (или `spawn` создаёт копии самого себя в начальных `var` больше 16 раз подряд) |
| TD405 | Внутренняя ошибка движка (не вина скрипта): обработчик остановлен, игра идёт дальше |

### Зарезервировано — `TD499`

| Код | Сообщение | Типичная причина |
|---|---|---|
| TD499 | Эта возможность пока не поддерживается в этой версии | сейчас выдаётся только на языковую конструкцию, которую интерпретатор не знает (признак ошибки в самом интерпретаторе); всё, что описано в [справочнике](reference.md), поддерживается |

## Примеры

**Пропущенное слово:**

```
Проблема в hero.tdsl, строка 3 (TD005):

    move right 5
               ^
Ожидалось слово «by»: например `move right by 5`.
```

**Опечатка в имени:**

```
Проблема в score.tdsl, строка 6 (TD101):

    coins += 1
    ^^^^^
Я не знаю переменной «coins». Есть похожая: «Coins». Имена различают
большие и маленькие буквы.
```

**Ошибка во время игры:**

```
Во время игры, hero.tdsl, строка 12 (TD302):

    print items[0]
          ^^^^^^^^
В списке «items» нет элемента с номером 0. Нумерация идёт с единицы:
первый элемент — items[1]. В списке сейчас 3 элемента.
Обработчик «when key space pressed» остановлен. Игра продолжается.
```

## Для разработчиков инструментов

- Сообщение всегда содержит: код, файл, строку, столбец (начало и конец подчёркивания), текст и необязательную подсказку.
- Подсказки «Может быть…» строятся по близости имён (расстояние Левенштейна ≤ 2) и совпадению без учёта регистра.
- Ошибки времени выполнения не завершают игру: обработчик прерывается, а остальные события продолжают обрабатываться.
