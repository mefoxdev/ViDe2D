# TrueDSL: справочник языка

> Версия спецификации **0.1 (черновик)**. Интерпретатор реализован не полностью: пока не работают `wait`, `slide`, звуки, `go to scene`, `restart scene`, `remember`/`recall`, `sin`/`cos` (при их выполнении выдаётся ошибка TD499, остальная игра идёт). До версии 1.0 детали могут измениться.

Если вы только начинаете — сначала прочитайте [тур на один день](tour.md). Это справочник: здесь всё сказано точно и коротко.

## 1. Как устроен скрипт

Скрипт — это файл `.tdsl` в кодировке UTF-8. Скрипт **прикрепляется к объекту** сцены, и этот объект внутри скрипта называется `self` («я»). Скрипт состоит из верхнеуровневых элементов:

| Элемент | Что это | Пример |
|---|---|---|
| `var` | переменная этого объекта | `var speed = 60` |
| `shared` | переменная всей игры | `shared coins = 0` |
| `when` | обработчик события | `when start` |
| `to` | своя команда (действие) | `to heal(amount)` |
| `use` | подключить файл с действиями | `use "helpers.tdsl"` |

Программа не имеет «главной функции»: игра — это набор объектов, каждый из которых **реагирует на события**.

## 2. Текст программы

- **Отступы.** Блок записывается со сдвигом ровно в **2 пробела** на уровень. Табуляция запрещена. Скобок `{ }` и точек с запятой нет.
- **Одна строка — одна инструкция.** Исключение: списки `[ ... ]` и скобки `( ... )` можно переносить на новые строки.
- **Комментарии:** `#` до конца строки.
- **Пустые строки** и строки только с комментарием игнорируются.
- **Имена:** буквы (в том числе русские), цифры и `_`; начинаются с буквы или `_`. Регистр важен: `score` и `Score` — разные имена. Принято писать `маленькими_буквами_с_подчёркиванием`.
- **Объекты сцены** вызываются по имени из панели Scene (`Hero`, `Coin`). Если в имени пробел или иные символы — используйте `find("Big Tree")`.

## 3. Значения и типы

В TrueDSL семь видов значений:

| Тип | Примеры | Заметки |
|---|---|---|
| число | `42`, `-3`, `0.5` | один тип для целых и дробных; 64-битное, одинаково считается на всех компьютерах |
| текст | `"Привет"`, `"Счёт: {score}"` | в двойных кавычках, в одну строку |
| да/нет | `yes`, `no` | |
| список | `[1, 2, 3]`, `[]` | нумерация **с единицы** |
| направление | `left`, `right`, `up`, `down` | настоящие значения: можно хранить в переменной |
| объект | `Hero`, `self`, `other` | персонаж или предмет сцены |
| ничего | `nothing` | «пусто», например когда `find` ничего не нашёл |

**Строгие правила (чтобы не было сюрпризов):**

- Условие в `if` / `while` обязано быть `yes` или `no`. Число или текст в условии — ошибка.
- Числа и текст сами не превращаются друг в друга. Чтобы вставить число в текст, используйте `{ }`: `"Жизней: {lives}"`. Из текста в число: `number("12")`.
- Сравнивать можно только значения одного типа.

### Текст и вставки

Внутри кавычек в фигурных скобках можно написать любое выражение: `"Счёт: {coins * 10}"`. Чтобы получить саму скобку, пишите `\{` и `\}`. Другие спецзнаки: `\"` (кавычка), `\\` (обратная косая), `\n` (новая строка).

### Списки

```
var items = ["меч", "щит"]
print items[1]            # меч — первый элемент
print items.length        # 2
print items.first         # меч
print items.last          # щит
items[2] = "лук"
```

Выход за границы списка (например `items[0]`) — ошибка с подсказкой, что нумерация с единицы.

## 4. Переменные и присваивание

```
var hp = 100              # объявить (один раз)
hp = 80                   # изменить
hp -= 5                   # то же, что hp = hp - 5
```

Операции присваивания: `=`, `+=`, `-=`, `*=`, `/=`.

- `var` внутри блока живёт только до конца блока; `var` наверху файла — **память объекта** (у каждого объекта своя копия).
- `shared` наверху файла — **общая память игры**. Объявляется в одном скрипте, доступна всем. Значение сохраняется при `go to scene`; `restart scene` начинает игру заново, и общие переменные возвращаются к начальным значениям.
- Нельзя объявить имя, которое уже существует (в том числе во внешнем блоке) — это ошибка, чтобы случайно не потерять переменную.
- Переменные других объектов читаются и меняются через точку: `Hero.hp -= 10`.

### Встроенные свойства объекта

Это не переменные, их не нужно объявлять. Внутри скрипта `x` — то же, что `self.x`. Названия зарезервированы.

| Свойство | Тип | Смысл |
|---|---|---|
| `x`, `y` | число | положение в пикселях (внутри группы — относительно группы); `x` растёт вправо, `y` — вниз |
| `width`, `height` | число | размер |
| `angle` | число | поворот в градусах |
| `visible` | да/нет | виден ли объект |
| `image` | текст | картинка проекта: имя файла (`"hero.png"`) или путь от папки проекта (`"assets/hero.png"`) |
| `tint` | текст | цвет-оттенок: `"red"`, `"#ff8800"` и т. д. |
| `flip` | да/нет | отзеркалить по горизонтали |
| `layer` | число | порядок рисования; больше — поверх |
| `tag` | текст | метка для групп: `"coin"`, `"enemy"` |
| `name` | текст | имя в сцене (только чтение) |
| `text`, `font_size` | текст, число | у объекта Text — надпись и размер шрифта |

Цвета по имени: `red`, `green`, `blue`, `yellow`, `orange`, `purple`, `pink`, `brown`, `white`, `black`, `gray`, `cyan`.

В режиме изображений **Pixel** объект рисуется по целым пикселям: дробная часть `x` и `y` сохраняется для расчётов, а на экране округляется.

## 5. Выражения

Порядок вычисления (сверху — сильнее):

| Уровень | Операции |
|---|---|
| 1 | точка `a.b`, индекс `a[1]`, вызов `f(x)`, скобки `( )` |
| 2 | унарный минус `-a` |
| 3 | `*`, `/`, `%` (остаток) |
| 4 | `+`, `-`, затем необязательное `per second` |
| 5 | сравнение: `is`, `is not`, `<`, `>`, `<=`, `>=`, `in`, `not in` |
| 6 | `not` |
| 7 | `and` |
| 8 | `or` |

- **Равенство** — это слово `is`: `if lives is 0`. Знак `=` бывает только в присваивании, `==` в языке нет.
- Цепочки сравнений (`1 < x < 5`) запрещены: пишите `x > 1 and x < 5`.
- `+` складывает числа или склеивает текст с текстом.
- `in` проверяет «входит ли»: `"меч" in items`, `"ab" in word`.
- **`per second` («в секунду»)** превращает величину в скорость: `60 per second` — это 60 пикселей за секунду, на каждый кадр достаётся 1/60 от неё. Так скорость не зависит от частоты кадров.

```
move right by speed per second
vy += 900 per second
```

### Клавиши и мышь

```
if key space is held       # клавиша зажата прямо сейчас
mouse.x    mouse.y         # положение курсора на игровом экране
mouse.held                 # кнопка мыши зажата (да/нет)
```

Названия клавиш: `left`, `right`, `up`, `down`, `space`, `enter`, `escape`, `shift`, `ctrl`, буквы `a`…`z`. Для остальных (например цифр) пишите в кавычках: `key "1"`.

## 6. Команды

Команды читаются как короткие фразы. **У команд нет скобок**, у функций — есть.

### Движение и вид

| Команда | Что делает |
|---|---|
| `move left by 5` | сдвинуть на 5 пикселей. Вместо `left` — `right`, `up`, `down` или переменная с направлением |
| `move right by 60 per second` | двигаться со скоростью 60 пикселей в секунду |
| `move right by 5 avoiding "wall"` | двигаться, но не заходить в объекты с меткой `wall` (остановится вплотную) |
| `move to 100, 50` | сразу перенести в точку (x, y) |
| `slide to 100, 50 in 2 seconds` | плавно переехать за 2 секунды (обработчик ждёт конца) |
| `turn by 90` / `turn by 180 per second` | повернуть / вращать |
| `show` / `hide` | показать / спрятать |

Отрицательная величина двигает в обратную сторону: `move down by -5` — это вверх.

### Объекты

| Команда | Что делает |
|---|---|
| `destroy` | удалить себя (в конце кадра) |
| `destroy other` | удалить указанный объект |
| `spawn "Star" at 10, 20` | создать копию шаблона `Star` в точке; можно сохранить: `var s = spawn "Star" at 10, 20` |

Удалённый или созданный объект на самом деле добавляется и исчезает **в конце кадра**. До этого момента он ещё «жив». Проверить, существует ли объект: `exists(obj)`.

### Звук и вывод

| Команда | Что делает |
|---|---|
| `play sound "jump.wav"` | проиграть звук |
| `play music "theme"` / `stop music` | включить / выключить музыку |
| `print "текст"` | вывести в консоль студии (для отладки) |

### Сообщения

```
send "game over"                  # всем объектам
send "hit" with 5                 # с числом, в обработчике оно называется value
send "open" to Door               # одному объекту
```

Принимаются в `when message "..."` (см. ниже). Сообщения доставляются **в конце кадра**, в порядке отправки; сообщения, отправленные при доставке, придут в следующем кадре — зациклиться невозможно.

### Время

```
wait 2 seconds             # подождать (остальная игра продолжает работать)
```

`wait` и `slide` приостанавливают **только этот обработчик**. Их нельзя использовать в `when update` и `when key … held` (они выполняются каждый кадр) — будет ошибка с объяснением.

### Сцены и сохранение

```
go to scene "level2"       # перейти на другую сцену (в конце кадра)
restart scene              # начать игру с этой сцены заново (общие переменные сбрасываются)
remember "best" as score   # запомнить значение между запусками игры
var best = recall("best", 0)   # достать (0 — если ничего не сохранено)
```

Запоминать можно числа, текст, да/нет и списки из них.

### Списки

| Команда | Смысл |
|---|---|
| `add "меч" to items` | добавить в конец |
| `remove "меч" from items` | убрать первое такое значение |
| `clear items` | очистить |
| `sort items` | отсортировать по возрастанию |
| `shuffle items` | перемешать |

## 7. Управление ходом программы

```
if hp <= 0
  print "конец"
else if hp < 20
  print "осторожно"
else
  print "всё хорошо"

repeat 3 times
  print "раз"

repeat forever                 # бесконечно — внутри нужен wait
  wait 1 second
  print "тик"

while n < 100
  n *= 2

for each item in items         # по списку
  print item

for each i in 1 to 5           # по числам 1, 2, 3, 4, 5
  print i

stop repeating                 # выйти из цикла
next round                     # перейти к следующему шагу цикла
```

## 8. События (`when`)

Событие — «когда случится X, сделай Y». У одного скрипта может быть сколько угодно обработчиков.

| Событие | Когда срабатывает |
|---|---|
| `when start` | один раз, когда объект появился в игре |
| `when update` | каждый кадр (60 раз в секунду) |
| `when key space pressed` | в кадр нажатия клавиши |
| `when key space held` | каждый кадр, пока клавиша зажата |
| `when key space released` | в кадр отпускания |
| `when click` | по этому объекту кликнули мышью / коснулись |
| `when touch "coin"` | объект начал касаться объекта с меткой `coin` (или конкретного объекта: `touch Door`) |
| `when stop touching "coin"` | перестал касаться |
| `when message "hit"` | пришло сообщение |
| `when every 2 seconds` | повторять каждые 2 секунды |

Внутри обработчика доступны особые слова:

| Слово | Где | Что это |
|---|---|---|
| `self` | везде | сам объект |
| `other` | `touch`, `stop touching` | второй объект |
| `value` | `message` | то, что отправили через `with` |

**Правила обработчиков:**

1. Обработчик никогда не запускается сам в себе: если он ещё ждёт (`wait`) и событие повторилось — повтор пропускается.
2. Порядок в кадре: ввод → `update` → таймеры `every` → касания → сообщения.
3. Объекты обрабатываются по порядку из панели Scene (сверху вниз, родитель перед детьми); обработчики одного объекта — в порядке записи в файле. Поэтому игра **полностью повторяема**: один и тот же ввод даёт один и тот же результат.

### Точные правила касаний, сообщений и создания объектов

Раздел описывает то, о чём выше сказано коротко. Всё это полностью повторяемо.

**Коробки.** Для касаний каждый объект — прямоугольник в мировых координатах:

- у объекта с размером (`width` и `height` больше нуля) это его прямоугольник; нулевой или отрицательный размер — это «нет размера» (такой объект и не рисуется);
- у объекта без размера (группа, экземпляр, обычный Node) это объединение прямоугольников его потомков: герой из нескольких спрайтов касается как одно тело (учитываются первые 256 потомков);
- если нет и их — это точка `(x, y)`.

Два объекта **касаются**, когда пересекаются больше чем на 0,000001 пикселя по обеим осям. Объекты «впритык» (край к краю) **не** касаются — они «стоят друг на друге»: это проверяет `touching("метка", down)`. Точка касается прямоугольника, если лежит внутри (левая и верхняя границы входят, правая и нижняя — нет). Объект не касается самого себя, своих родителей и своих потомков. Невидимые объекты касаются тоже. Объект, который удалён командой `destroy` в этом кадре, до конца кадра ещё «жив» и касается.

**События касаний.** `when touch "метка"` срабатывает один раз для каждого объекта, который начал касаться: в кадр, когда касание началось (и в первый кадр жизни, если объекты уже перекрываются). Несколько объектов, начавших касаться в один кадр, обрабатываются в порядке сцены. `when stop touching` срабатывает в кадр, когда касание закончилось. Если второй объект при этом **удалён** или его кусок карты выгружен, `stop touching` не срабатывает: объект просто исчез (у выгруженных чанков объектов нет вообще — они не касаются и не находятся через `find`/`all`; когда чанк загрузится снова, касание начнётся заново). После `touch` объект записан в `other`. Аргумент события (`"coin"` или `Door`) вычисляется каждый кадр: если это объект, которого нет, никто не касается.

**Движение с препятствиями.** `move right by 5 avoiding "wall"` останавливается вплотную к первому объекту с меткой `wall` на пути (быстрое движение не «пролетает» сквозь стену). Объекты, в которых герой уже находится, не мешают выйти из них. `touching("метка", down)` — есть ли объект с меткой, стоящий впритык в этом направлении (зазор до 0,001 пикселя считается «впритык»).

**Расстояние.** `distance(a, b)` — расстояние между центрами коробок двух объектов. `find("имя")` и имя объекта в коде (`Hero`) дают первый подходящий объект в порядке сцены; `all("метка")` — список в порядке сцены.

**Создание и удаление.** `spawn "Шаблон" at x, y` создаёт копию шаблона (объект сцены с галочкой Template) вместе с вложенными объектами, скриптом и меткой; `x`, `y` — мировые координаты, у копии нет родителя. Копия сразу существует для скриптов (можно взять `var s = spawn ...`, прочитать и изменить её переменные и свойства, `exists(s)` даёт `yes`), но входит в игру — виден, касается, получает `when start`, находится через `find`/`all`/`count` — **в следующем кадре**. До этого её не видят ни `touching`, ни `overlapping`, ни клики; `distance` до неё даёт ошибку TD303. Если шаблон в своих начальных `var` снова делает `spawn`, цепочка обрывается ошибкой TD404 после 16 вложений. Одновременно может жить не больше 5 000 объектов, созданных через `spawn`, иначе ошибка TD403. `destroy other` / `destroy Имя` удаляют объект в конце кадра.

**Сообщения.** `send` кладёт сообщение в очередь; в конце кадра (после касаний) очередь доставляется: сообщения идут **в порядке отправки**, каждое — всем объектам со скриптом в порядке сцены (или одному, если есть `to`). Сообщение, отправленное во время доставки, придёт в конце следующего кадра. За кадр можно отправить не больше 1 000 сообщений (ошибка TD402); если ждущих доставки больше 5 000, отправка тоже отказывает. Если в кадре не хватило шагов (200 000), недоставленные сообщения остаются в очереди в том же порядке; сообщение, которое не успели разослать всем, в следующем кадре продолжает рассылку со следующего получателя — никто не получает его дважды и никто не остаётся без него. `value` — то, что отправлено через `with`, а если `with` не было — `nothing`. Адресат `to`, которого к моменту доставки уже нет (удалён в прошлом кадре или выгружен), сообщения не получает.

**Мышь.** `mouse.x`, `mouse.y` — положение курсора в **мировых координатах** (с учётом камеры и масштаба окна), `mouse.held` — зажата ли левая кнопка (или касание пальцем). `when click` срабатывает в кадр нажатия кнопки у **каждого** объекта с таким обработчиком, коробка которого содержит курсор, в порядке сцены; границы — как у точки при касании: левая и верхняя входят, правая и нижняя нет. Кнопка, которая уже была зажата в момент запуска игры (клик по кнопке «Запустить»), кликом не считается.

**Общие переменные и чужие переменные.** Все скрипты проекта компилируются до первого кадра, и каждая `shared` получает начальное значение один раз (от первого объявившего), поэтому порядок объектов не важен. Скрипт, не привязанный ни к одному объекту, тоже может объявить `shared` для остальных. `Hero.hp` читает и меняет переменную `var hp` из скрипта объекта `Hero`; у объекта без скрипта или без такой переменной — ошибка TD106. Начальные значения `var` всех объектов вычисляются **до** первого `when start` любого объекта.

**Подключение файлов.** `use "helpers.tdsl"`: имя без `/` ищется в папке `scripts`, путь с `/` — от папки проекта; нужен файл `.tdsl` внутри проекта (без `..`, абсолютных путей и ссылок). Из файла берутся только команды `to`, всё остальное в нём игнорируется с предупреждением. Команда из файла работает от лица вызвавшего объекта: `hp` в ней — переменная вызвавшего. Если у вас и у файла команды с одним именем, побеждает ваша.

## 9. Свои команды (`to`)

```
to heal(amount)
  hp = min(hp + amount, 100)

to double(n)
  return n * 2

when key h pressed
  heal(20)
  print "стало {double(hp)}"
```

- Действие вызывается как `имя(значения)`. Если оно делает `return` — результат можно использовать в выражении.
- Действие выполняется от лица того объекта, который его вызвал (`x`, `hp` и т. д. — его).
- `use "helpers.tdsl"` подключает действия из другого файла проекта (только `to`, без `when` и переменных). Путь — внутри проекта, без `..`.

## 10. Встроенные функции

**Числа:** `abs(x)`, `min(a, b)`, `max(a, b)`, `round(x)`, `floor(x)`, `ceil(x)`, `sqrt(x)`, `sin(deg)`, `cos(deg)` (углы в градусах), `random(a, b)` (целое от a до b включительно), `pick(list)` (случайный элемент).

**Текст:** `upper(t)`, `lower(t)`, `number(t)` (из текста в число; ошибка, если не число), `t.length`.

**Объекты:** `find("имя")` (объект или `nothing`), `all("метка")` (список объектов с меткой), `count("метка")`, `exists(obj)`, `distance(a, b)` (между объектами), `touching("метка")` (касаюсь ли сейчас), `touching("метка", down)` (стоит ли что-то вплотную в этом направлении).

**Направления:** `opposite(dir)` (`left` ↔ `right`, `up` ↔ `down`).

**Память:** `recall("ключ", запасное_значение)`.

`random` повторяема: игра запускается с фиксированным зерном, когда это нужно (например в турнире или записи повтора).

## 11. Грамматика (EBNF)

Для разработчиков инструментов. `INDENT` / `DEDENT` — сдвиг на 2 пробела вправо / влево, `NL` — конец строки.

```
script      = { NL | item } ;
item        = var_decl | shared_decl | use_decl | action_def | handler ;

var_decl    = "var" NAME "=" expr NL ;
shared_decl = "shared" NAME "=" expr NL ;
use_decl    = "use" TEXT NL ;
action_def  = "to" NAME "(" [ NAME { "," NAME } ] ")" NL block ;
handler     = "when" event NL block ;

event       = "start" | "update"
            | "key" key ( "pressed" | "released" | "held" )
            | "click"
            | "touch" expr
            | "stop" "touching" expr
            | "message" expr
            | "every" expr unit ;
key         = NAME | TEXT ;
unit        = "second" | "seconds" ;

block       = INDENT statement { statement } DEDENT ;
statement   = var_decl | assignment | if_stmt | repeat_stmt | while_stmt | for_stmt
            | "stop" "repeating" NL | "next" "round" NL
            | "return" [ expr ] NL
            | command NL | call NL ;

assignment  = target ( "=" | "+=" | "-=" | "*=" | "/=" ) expr NL ;
target      = NAME | postfix "." NAME | postfix "[" expr "]" ;

if_stmt     = "if" expr NL block { "else" "if" expr NL block } [ "else" NL block ] ;
repeat_stmt = "repeat" expr "times" NL block | "repeat" "forever" NL block ;
while_stmt  = "while" expr NL block ;
for_stmt    = "for" "each" NAME "in" ( expr | additive "to" additive ) NL block ;

command     = "move" ( dir_expr "by" expr [ "avoiding" expr ] | "to" expr "," expr )
            | "slide" "to" expr "," expr "in" expr unit
            | "turn" "by" expr
            | "show" | "hide"
            | "destroy" [ expr ]
            | spawn
            | "play" ( "sound" | "music" ) expr | "stop" "music"
            | "print" expr
            | "send" expr [ "with" expr ] [ "to" expr ]
            | "wait" expr unit
            | "go" "to" "scene" expr | "restart" "scene"
            | "remember" expr "as" expr
            | "add" expr "to" expr | "remove" expr "from" expr
            | "clear" expr | "sort" expr | "shuffle" expr ;
dir_expr    = "left" | "right" | "up" | "down" | NAME ;
spawn       = "spawn" expr "at" expr "," expr ;

expr        = or_expr ;
or_expr     = and_expr { "or" and_expr } ;
and_expr    = not_expr { "and" not_expr } ;
not_expr    = "not" not_expr | compare ;
compare     = additive [ ( "is" [ "not" ] | "<" | ">" | "<=" | ">=" | [ "not" ] "in" ) additive ] ;
additive    = term { ( "+" | "-" ) term } [ "per" "second" ] ;
term        = unary { ( "*" | "/" | "%" ) unary } ;
unary       = "-" unary | postfix ;
postfix     = primary { "." NAME | "[" expr "]" } ;
primary     = NUMBER | TEXT | "yes" | "no" | "nothing"
            | "left" | "right" | "up" | "down"
            | "self" | "other" | NAME
            | "(" expr ")" | "[" [ expr { "," expr } ] "]"
            | NAME "(" [ expr { "," expr } ] ")"
            | "key" key "is" "held"
            | spawn ;
call        = NAME "(" [ expr { "," expr } ] ")" ;
```

В `per second` слово `per` и `second` — ключевые.

### Зарезервированные слова

`add and as at avoiding by clear destroy down each else every for forever from go held hide if in is key left message move next no not nothing of or other per play print released remember remove repeat repeating restart return right round scene second seconds self send shared show shuffle slide sort spawn start stop sound music times to touch turn up update use value var wait when while with yes click pressed mouse`

и имена свойств: `x y width height angle visible image tint flip layer tag name text font_size`.

Их нельзя использовать как имена своих переменных и действий. Имена встроенных функций (`find`, `all`, `touching`, `random` и др.) тоже заняты. Слово `touching` — особый случай: оно работает и как функция `touching(...)`, и как часть события `stop touching`.
