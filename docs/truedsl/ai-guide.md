# TrueDSL для ИИ-ассистентов

Эта страница — инструкция для языковых моделей, которые пишут TrueDSL, и для людей, которые просят их об этом. Её можно целиком вставить в запрос к ИИ. TrueDSL специально устроен так, чтобы код, написанный ИИ, был читаем для человека и проверяем машиной.

## Короткая инструкция (вставьте в запрос)

```
Ты пишешь код на TrueDSL — языке 2D-игр ViDe2D. Правила:
1. Используй только то, что описано в справочнике TrueDSL. Не придумывай команды.
2. Отступ — ровно 2 пробела, без табуляции. Нет скобок {} и точек с запятой.
3. Равенство — `is` (не `==`). Присваивание — `=`, `+=`, `-=`, `*=`, `/=`.
4. Условия — только yes/no. Нет «истинности» чисел и текста.
5. Числа в тексте — через "{выражение}", не через "+".
6. Списки нумеруются с 1.
7. Игра — это обработчики событий `when ...`. Нет главного цикла.
8. Скорость — `... per second`. Не умножай на dt.
9. `wait` и `slide` запрещены в `when update` и `when key ... held`.
10. Объекты общаются через `send "сообщение"` и `when message "..."`.
11. Не используй имена: x y width height angle visible image tint flip layer tag name text
    font_size value other self mouse и ключевые слова.
12. Сначала спроси или посмотри список объектов сцены, их метки (tag) и ресурсы в assets.
```

## Золотые правила

1. **Один способ — одно действие.** В TrueDSL для каждой задачи есть единственная каноническая запись. Если вы колеблетесь между двумя вариантами — один из них не существует.
2. **Пишите событиями.** Всё, что происходит в игре, привязано к `when …`. Если вы хотите написать «цикл игры», вам нужен `when update`.
3. **Не изобретайте API.** Нет `import`, `class`, `function`, `list.append`, `console.log`, `self.x = …` (вместо этого просто `x = …`, но `Hero.x = …` — для другого объекта).
4. **Читаемость важнее краткости.** Код читают дети и новички. Давайте переменным понятные имена и комментируйте нетривиальные места на языке пользователя.
5. **Каждый скрипт отвечает за один объект.** Если объектам надо что-то согласовать — используйте сообщения и `shared`.

## Таблица «неправильно → правильно»

| ❌ Привычка из других языков | ✅ TrueDSL |
|---|---|
| `if lives == 0:` | `if lives is 0` |
| `if (lives == 0) { ... }` | отступы вместо скобок |
| `def jump(power):` / `function jump(power)` | `to jump(power)` |
| `for i in range(5):` | `for each i in 1 to 5` |
| `for (i = 0; i < 5; i++)` | `for each i in 1 to 5` |
| `x = x + speed * dt` | `x += speed per second` или `move right by speed per second` |
| `print("Счёт: " + str(score))` | `print "Счёт: {score}"` |
| `items.append(x)` | `add x to items` |
| `items[0]` | `items[1]` |
| `len(items)` | `items.length` |
| `self.x += 1` | `x += 1` |
| `true` / `false` / `null` | `yes` / `no` / `nothing` |
| `elif` / `else if (…)` | `else if …` (без скобок) |
| `while True:` | `repeat forever` (с `wait` внутри) |
| `break` / `continue` | `stop repeating` / `next round` |
| `import helpers` | `use "helpers.tdsl"` |
| `sleep(1)` | `wait 1 second` |
| `Hero.position.x` | `Hero.x` |
| `dir = "left"` (текстом) | `heading = left` (значение-направление) |
| `if score:` | `if score > 0` |

## Идиомы: готовые шаблоны

**Движение с клавиш**

```
when key left held
  move left by 80 per second
```

**Прыжок и гравитация**

```
var vy = 0

when key space pressed
  if touching("floor", down)
    vy = -280

when update
  vy += 800 per second
  move down by vy per second avoiding "floor"
  if touching("floor", down) and vy > 0
    vy = 0
```

**Сбор предметов и счётчик** (герой посылает сообщение, счётчик считает)

```
when touch "coin"
  destroy other
  send "coin collected"
```

**Появление объектов по таймеру**

```
when every 2 seconds
  spawn "Enemy" at random(10, 300), 0
```

**Патруль**

```
var heading = right

when update
  move heading by 40 per second avoiding "wall"
  if touching("wall", heading)
    heading = opposite(heading)
```

**Пауза и последовательность**

```
when message "game over"
  hide
  wait 2 seconds
  restart scene
```

**Рекорд**

```
when message "game over"
  if score > recall("best", 0)
    remember "best" as score
```

## Проверочный список перед ответом

Перед тем как показать код, проверьте:

- [ ] Отступы — ровно по 2 пробела, нет табуляции.
- [ ] Нет `==`, `!=`, `&&`, `||`, `;`, `{}` кроме вставок в текст, нет `null`, `True`, `elif`.
- [ ] В условиях только `yes`/`no`.
- [ ] Нет `wait` / `slide` в `when update` и `when key … held`.
- [ ] Все переменные объявлены (`var` / `shared`) до использования; имена не конфликтуют со свойствами объекта.
- [ ] Списки нумеруются с единицы; нет `items[0]`.
- [ ] Метки в `touch`/`avoiding`/`all` соответствуют меткам в сцене.
- [ ] Звуки и картинки есть в папке `assets` проекта.
- [ ] Для каждого `send "x"` есть `when message "x"` (и наоборот).
- [ ] Ответ содержит имена файлов и к каким объектам они прикрепляются.

## Как лучше формулировать запрос ИИ

Хороший запрос содержит:

1. что должно происходить словами («герой собирает монеты, за каждую +1, на пятой — победа»);
2. список объектов и их меток (`Hero`, `Coin` с меткой `coin`, надпись `Score`);
3. какие ассеты есть (`coin.wav`, `hero.png`);
4. требуемые события (по какой клавише, по какому касанию).

Если чего-то не хватает, ИИ должен задать вопрос, а не угадывать.

## Если инструмент выдал ошибку

Ошибки TrueDSL содержат код (`TD101` и т. п.), строку и подсказку. Передайте ИИ **всё сообщение целиком вместе с кодом ошибки** — его хватает, чтобы исправить без догадок. См. [Ошибки](errors.md).
