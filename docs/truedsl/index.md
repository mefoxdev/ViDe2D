# TrueDSL — язык для игр ViDe2D

TrueDSL (сокращённо **TDSL**, файлы `.tdsl`) — язык программирования, на котором пишутся игры в ViDe2D. Он создан для трёх групп людей:

- **дети и школьники**, которые делают первую игру;
- **начинающие**, которые никогда не программировали;
- **ИИ-ассистенты**, которые пишут код по описанию человека.

> **Статус: спецификация 0.1 (черновик).** Язык описан полностью, но интерпретатор и редактор VCode ещё в разработке. До версии 1.0 детали могут меняться.

## Как выглядит TrueDSL

```
var speed = 80

when key right held
  move right by speed per second

when touch "coin"
  destroy other
  play sound "coin.wav"
  send "coin collected"
```

Прочитайте вслух: «Когда зажата клавиша вправо — двигайся вправо со скоростью speed в секунду. Когда коснулся монеты — удали её, проиграй звук и сообщи, что монета собрана».

Если вы поняли, что делает этот код, — вы уже читаете TrueDSL.

## Цели

| Цель | Как достигается |
|---|---|
| **Прочитать за день** | код читается как предложения на английском: `move right by 5`, `when touch "coin"`, `wait 2 seconds` |
| **Понимать за неделю** | всего несколько идей: события, переменные, условия, циклы, сообщения |
| **Удобен для 2D** | движение, касания, камера-экран, спрайты, звук, таймеры и сцены — встроены в язык, а не в библиотеки |
| **Безопасен** | в языке нет доступа к файлам, сети и системе; жёсткие лимиты; игры работают в песочнице |
| **Удобен для ИИ** | у каждой задачи один каноничный способ, строгие типы, понятные коды ошибок |

## Принципы дизайна

1. **Читается как предложение.** Команды — глаголы: `move`, `show`, `play`, `send`, `wait`. Нет символов, которые надо расшифровывать.
2. **Игра — это реакции на события.** Не нужно писать «главный цикл». Вы пишете: «когда нажата клавиша… когда коснулся… когда пришло сообщение…».
3. **Один способ — одно действие.** Нет трёх видов циклов, двух видов равенства, лишних сокращений.
4. **Никакой скрытой магии.** Условие — только «да» или «нет». Числа и текст не превращаются друг в друга сами. Равно проверяется словом `is`, а `=` только кладёт значение.
5. **Ошибки — на человеческом языке.** Каждая ошибка говорит, где и что случилось, и предлагает исправление.
6. **Безопасность по построению.** Опасных команд нет в языке, а ресурсы ограничены.
7. **Повторяемость.** Одинаковый ввод — одинаковый результат. Это даёт честные турниры и воспроизводимые баги.

## Как TrueDSL встраивается в ViDe2D

- Скрипт `.tdsl` **прикрепляется к объекту** сцены в ViDe-studio; сам объект в скрипте называется `self`.
- Редактировать скрипты удобно в **VCode** — с подсветкой, подсказками и понятными ошибками.
- Картинки из **Vimg** и музыка из **Vtune** подключаются по имени файла из папки `assets`: `play sound "jump.wav"`, `image = "hero.png"`.
- Готовую игру можно опубликовать в **ViDe-store**: перед публикацией скрипты проверяются.
- Для локальных сетей и турниров **VLS** запускает игры одинаково у всех игроков — благодаря повторяемости TrueDSL.

## Что дальше в планах

Язык версии 0.1 намеренно маленький. Рассматриваются для следующих версий: анимации спрайтов, камера, карты тайлов, сетевая игра через VLS, словари («записи»), русские названия команд. Всё это будет добавляться так, чтобы старые игры продолжали работать.
